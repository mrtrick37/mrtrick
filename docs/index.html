Bazzite Setup Guide

Fedora Atomic • Gaming-First

No Linux knowledge required. Everything works out of the box with Steam Deck UI mode, automatic updates, and all gaming tools pre-installed. Perfect for Windows switchers.

  • Zero configuration needed
  • Steam Deck mode available
  • Nvidia variants included
  • Atomic rollback if issues occur

CachyOS Setup Guide

Arch-Based • Maximum FPS

Maximum FPS and system responsiveness with a performance-tuned kernel, BORE scheduler, and PGO/LTO optimized packages. Requires some Linux familiarity.

  • BORE + sched-ext schedulers
  • PGO/LTO optimized packages
  • Full AUR access
  • Hardware-specific kernel builds

Nobara Setup Guide

Fedora + Gaming Patches

A gaming-focused Fedora spin maintained by GloriousEggroll (creator of Proton-GE). Practical defaults, updated packages, and a straightforward setup for Steam and Proton.

  • fsync / futex2 kernel patches
  • OBS & streaming tools included
  • Good freshness / stability balance
  • Fast Steam Play setup
