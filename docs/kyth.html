Overview — What is KythOS?

KythOS is a Fedora-based atomic Linux image built for gaming and productivity. It's delivered as an OCI container image using the bootc system (from the Universal Blue / Fedora ecosystem), which means the entire base system is treated as a versioned, immutable artifact.

Key Design Principles

  • Immutable base — The root filesystem is read-only. System files can't be accidentally broken by user actions or bad package updates.
  • Atomic updates — Updates are whole image swaps pulled in the background. Apply on next reboot. If something goes wrong, roll back with one command.
  • Flatpak-first apps — Applications live in Flatpak sandboxes, separate from the base OS. Install, remove, and update apps without touching the system.
  • Distrobox for everything else — Need a package not in Flatpak? Spin up a Distrobox container (Arch, Ubuntu, Fedora, etc.) and use it transparently from your desktop.
  • Gaming ready at first boot — Steam, Proton, MangoHud, GameMode, and Vulkan drivers come pre-configured. No setup required.
Based on Fedora. KythOS tracks Fedora's stable releases, giving you a current kernel, up-to-date Mesa, and modern hardware support — while the atomic model keeps your system stable.

Installation

System Requirements

  • CPU: x86_64 (AMD or Intel), 4+ cores recommended
  • RAM: 8 GB minimum, 16 GB recommended for gaming
  • Storage: 50 GB minimum, 100 GB+ recommended
  • GPU: AMD (open drivers), Intel (integrated/Arc), or Nvidia (use Nvidia variant)
  • Boot: UEFI required (Legacy BIOS is not supported)
  • USB: 8 GB or larger for installation media

Step 1: Download

Download the latest KythOS ISO from GitHub Releases. Select the variant for your hardware:

  • AMD/Intel — open-source Mesa drivers, works for most hardware
  • Nvidia — includes proprietary Nvidia drivers pre-installed
  • KDE Plasma or GNOME — choose your preferred desktop
Download Latest KythOS →

Step 2: Create Bootable USB

Flash the ISO to a USB drive using one of these tools:

  • Fedora Media Writer — recommended for Fedora-based images
  • Balena Etcher — simple cross-platform tool
  • Ventoy — allows multiple ISOs on one USB stick
This will erase the USB drive. Back up any data on it before flashing.

Step 3: Boot from USB

Reboot your computer. Enter the boot menu — usually by pressing F12, F2, Esc, or Del during startup (varies by motherboard). Select your USB drive. If you see a Secure Boot error, disable Secure Boot in UEFI settings temporarily.

Step 4: Run the Installer

KythOS uses the Anaconda installer (same as Fedora). You'll configure:

  • Language & Keyboard — select your region
  • Installation Destination — choose your disk (automatic partitioning recommended for most users)
  • Timezone — or let NTP handle it automatically
  • Root Password / User Account — create your user with administrator privileges

Click Begin Installation. This takes 10–20 minutes. When done, click Reboot and remove the USB drive.

Post-Install Setup

Complete First-Boot Setup

On first login, the desktop setup wizard will run (GNOME Initial Setup or KDE Welcome). Complete it to configure your timezone, online accounts, and privacy settings.

Check for Updates

After first boot, check for a newer image:

bootc upgrade

If an update is available, it will download in the background. Reboot to apply it.

Verify GPU Drivers

Confirm your GPU is recognized correctly:

glxinfo | grep "OpenGL renderer"
vulkaninfo --summary

AMD users should see a RadeonSI or RADV renderer. Nvidia users should see an Nvidia renderer. Intel users should see ANV or i965.

Set Up Flathub

Flathub is the main Flatpak app repository. It may already be configured, but you can verify:

flatpak remote-list
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Gaming Setup

Steam & Proton

Steam is pre-installed in KythOS. To enable Windows game compatibility:

  1. Open Steam → Settings → Compatibility
  2. Enable "Enable Steam Play for all other titles"
  3. Select Proton (latest stable) as the default compatibility tool
  4. Restart Steam

You can now install and run most Windows games directly through Steam.

Proton-GE (Extended Compatibility)

Proton-GE is a community fork of Proton with more patches and fixes. It often fixes games that don't work on Proton stable.

flatpak install flathub net.davidotek.pupgui2

Open ProtonUp-Qt, select Steam as the launcher, and install the latest Proton-GE version. Then in Steam, right-click a game → Properties → Compatibility → select Proton-GE.

Non-Steam Launchers

  • Heroic Games Launcher — Epic Games Store and GOG. Install via Flatpak: flatpak install flathub com.heroicgameslauncher.hgl
  • Lutris — covers Battle.net, EA App, Ubisoft Connect, and custom Wine prefixes: flatpak install flathub net.lutris.Lutris
  • Bottles — run any Windows application in an isolated Wine prefix: flatpak install flathub com.usebottles.bottles

MangoHud (Performance Overlay)

MangoHud is pre-installed. Add it to any Steam game via launch options:

MANGOHUD=1 %command%

Or for Vulkan games specifically:

mangohud %command%

Configure MangoHud by editing ~/.config/MangoHud/MangoHud.conf.

GameMode

GameMode temporarily boosts CPU governor and tweaks system parameters while a game is running. It's pre-installed and active. Add it to Steam launch options:

gamemoderun %command%

Combine with MangoHud: MANGOHUD=1 gamemoderun %command%

Checking Game Compatibility

Before buying or installing a game, check ProtonDB.com. Reports from other Linux users include:

  • Overall compatibility rating (Platinum, Gold, Silver, Bronze, Borked)
  • Specific launch options or fixes needed
  • Anti-cheat status (EAC/BattlEye Linux support)

Controller Support

Most controllers work out of the box via Steam Input or the kernel's HID layer:

  • Xbox controllers — plug in via USB or pair via Bluetooth
  • PlayStation controllers — supported via USB or Bluetooth; DualSense haptics work in some games
  • Nintendo Switch Pro / Joy-Con — supported via hid-nintendo kernel module
  • Steam Controller — fully supported via Steam

Productivity & Development

Flatpak Applications

Install productivity apps from Flathub — they're sandboxed and work independently of the base OS:

flatpak install flathub org.libreoffice.LibreOffice
flatpak install flathub com.obsproject.Studio
flatpak install flathub com.visualstudio.code
flatpak install flathub org.gimp.GIMP
flatpak install flathub org.inkscape.Inkscape

Browse all available apps at flathub.org.

Development with Distrobox

Distrobox lets you run any Linux distribution as a container, accessible from your desktop. Use it to install packages that aren't available as Flatpaks or in the base image:

# Create an Arch Linux environment
distrobox create --name arch --image archlinux:latest
distrobox enter arch

# Create an Ubuntu environment
distrobox create --name ubuntu --image ubuntu:24.04
distrobox enter ubuntu

You can even export GUI apps from a Distrobox container to your desktop menu.

Layering Packages (Advanced)

For system-level packages, you can layer them onto the KythOS base image using rpm-ostree. Use this sparingly — prefer Flatpak or Distrobox when possible:

# Layer a package onto the base system
rpm-ostree install htop

# List layered packages
rpm-ostree status
Layered packages persist across image updates but can sometimes cause conflicts. For most software, Flatpak or Distrobox is a better option.

Development Containers

KythOS ships with Podman for running OCI containers. Use it for dev environments, services, or testing:

podman run -it --rm ubuntu:24.04 bash
podman run -d -p 5432:5432 postgres:16

Updates & Rollback

Checking for Updates

bootc upgrade

This checks the remote image registry for a newer version and downloads it if available. Updates are staged — they don't apply until the next reboot.

Applying Updates

Simply reboot. KythOS will boot into the new image. Your home directory, Flatpak apps, and Distrobox containers are untouched.

Rolling Back

If an update breaks something, roll back to the previous deployment:

bootc rollback

Then reboot. You'll be on the previous image. Report the issue on GitHub so it can be fixed.

Checking Current Status

bootc status

Shows the currently booted image, staged image (if any), and rollback image.

KythOS can be configured to check for and stage updates automatically via a systemd timer. This means updates are always ready and waiting — just reboot when convenient.

Flatpak Updates

Flatpak apps update independently of the base image:

flatpak update

Or use GNOME Software / KDE Discover to update Flatpaks with a GUI.

Customization

Desktop Theming

Customize your desktop environment using the built-in tools:

  • KDE Plasma — System Settings → Appearance for themes, icons, fonts, and colors
  • GNOME — Install GNOME Tweaks via Flatpak for additional customization options

Kernel Arguments

Add or modify kernel parameters for advanced tuning:

# Add a kernel argument
sudo rpm-ostree kargs --append="mitigations=off"

# Remove a kernel argument
sudo rpm-ostree kargs --delete="quiet"

# List current kernel arguments
rpm-ostree kargs
Disabling CPU mitigations (mitigations=off) can improve performance but reduces security. Only do this on trusted hardware used exclusively for gaming.

Building a Custom KythOS Image

Since KythOS is an OCI image, you can fork it and add your own customizations using a Containerfile:

FROM ghcr.io/mrtrick37/mrtrick:latest

RUN rpm-ostree install vim neovim && \
    rpm-ostree cleanup -m && \
    ostree container commit

See the GitHub repo for the base Containerfile and build instructions.

Troubleshooting

Game Won't Launch

  • Right-click the game in Steam → Properties → Compatibility → Force a specific Proton version
  • Try Proton-GE (install via ProtonUp-Qt) — it has more patches than Proton stable
  • Check ProtonDB for known fixes and launch options
  • Verify game files in Steam (right-click → Properties → Local Files → Verify integrity)
  • Check Steam launch output by running Steam from the terminal: steam

Poor Performance / Low FPS

  • Add gamemoderun %command% to the game's Steam launch options
  • Use MangoHud (MANGOHUD=1 %command%) to identify the bottleneck (CPU, GPU, VRAM)
  • Check that the correct GPU is being used: glxinfo | grep renderer
  • For AMD: ensure Mesa is up to date (bootc upgrade)
  • Set the CPU governor to performance mode: echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

GPU / Driver Issues

  • AMD: verify Mesa is loaded correctly with LIBGL_DEBUG=verbose glxinfo
  • Nvidia: check driver status with nvidia-smi
  • If you installed the wrong variant (e.g., AMD image on Nvidia), reimage with the correct variant

Audio Not Working

  • Check PipeWire is running: systemctl --user status pipewire
  • Restart audio: systemctl --user restart pipewire wireplumber
  • Use pavucontrol (install via Flatpak) for detailed audio routing
  • For game audio issues, try adding PULSE_LATENCY_MSEC=60 %command% to Steam launch options

Update Fails or System Won't Boot After Update

  • At the GRUB menu, select the previous deployment entry to boot the old image
  • Once booted, run: bootc rollback then reboot to make the rollback permanent
  • Report the issue on GitHub Issues with your bootc status output

Command Reference

System Updates (bootc)

bootc status # Show current, staged, and rollback images
bootc upgrade # Download latest image (staged, applied on reboot)
bootc rollback # Stage the previous image (applied on reboot)

Package Layering (rpm-ostree)

rpm-ostree status # Show deployment status
rpm-ostree install <package> # Layer a package onto the base
rpm-ostree uninstall <package> # Remove a layered package
rpm-ostree upgrade # Check for base image updates (legacy)
rpm-ostree rollback # Roll back to previous deployment
rpm-ostree kargs --append="<arg>" # Add a kernel argument

Flatpak

flatpak install flathub <app-id> # Install an app from Flathub
flatpak update # Update all Flatpak apps
flatpak uninstall <app-id> # Remove an app
flatpak list # List installed Flatpak apps
flatpak remote-list # List configured repositories

Distrobox

distrobox create --name <name> --image <image> # Create a container
distrobox enter <name> # Enter a container
distrobox list # List all containers
distrobox rm <name> # Remove a container
distrobox-export --app <app> # Export GUI app to desktop

Gaming

# MangoHud overlay
MANGOHUD=1 %command%

# GameMode performance boost
gamemoderun %command%

# Combined (add to Steam launch options)
MANGOHUD=1 gamemoderun %command%

# Check GPU renderer
glxinfo | grep "OpenGL renderer"
vulkaninfo --summary
