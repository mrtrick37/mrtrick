What is KythOS?

Atomic. Immutable. Gaming-ready.

KythOS is a Fedora Kinoite–based atomic image built on the Universal Blue toolchain. The base system is read-only and managed as an OCI container image — updates are reliable, rollbacks are instant, and gaming works from first boot.

🔒

Atomic & Immutable

The base system is read-only. Updates apply as whole image swaps and roll back instantly — no more broken systems after a bad update.

🎮

Gaming Ready at First Boot

Steam, Proton, MangoHud, GameMode, and Vulkan drivers are pre-installed and pre-configured. Install and play — no manual setup required.

🛠️

Productivity Without Compromise

Flatpak apps, development tools via Distrobox, and a stable base that won't break when you update. Game and work on the same machine, no tradeoffs.

📦

OCI Image Architecture

KythOS is delivered as a container image using bootc. Updates pull in the background and apply on reboot — like Android system updates, but for your desktop.

🦊

Fedora Kinoite Base

Built on Fedora Kinoite with the CachyOS kernel — Fedora's hardware support and Mesa drivers, with BORE scheduling and low-latency tuning on top.

🌐

Community Driven

Built by the community, for the community. Shape where KythOS goes next — join the Discord, file issues on GitHub, or submit a pull request.

KythOS is built on Fedora Kinoite using the Universal Blue / bootc toolchain. The image is published to GitHub Container Registry (ghcr.io) and updates in the background. When a new version is ready, you reboot — that's it. No package manager conflicts, no half-applied updates, no broken systems.

  • Atomic image swaps via bootc
  • Instant rollback to previous deployment
  • Steam, Proton & MangoHud pre-installed
  • Flatpak-first app management
  • Distrobox for any Linux environment
  • Active community on Discord & GitHub

How It Works

Atomic updates, explained simply

KythOS uses image-based updates instead of traditional package management. Here's what that means in practice.

1️⃣

Install Once

Flash the ISO, boot, and run the installer. KythOS sets up your immutable base. Your home directory, Flatpaks, and Distrobox containers are separate from the base — they persist across every update.

2️⃣

Updates in the Background

KythOS pulls the latest image from ghcr.io while you work or game. When an update is staged, you'll get a notification. Your current session is never interrupted.

3️⃣

Reboot to Apply

Reboot to switch to the new image. If anything goes wrong, a single command rolls you back to the previous deployment instantly.
