Installation Guide

Quick Start — KythOS

Get KythOS up and running fast. Step-by-step from download to first boot, with gaming fully configured. Also includes quick start guides for other community-recommended distros.

Primary — KythOS

KythOS

Custom atomic image for gaming & productivity

1

Download the ISO

Grab the latest KythOS release from GitHub. Choose the variant that matches your GPU:

  • AMD / Intel — recommended for most users (open-source Mesa drivers)
  • Nvidia — includes proprietary Nvidia driver pre-installed
  • KDE Plasma or GNOME desktop environment variants available
Download KythOS on GitHub →
2

Create a Bootable USB

Flash the downloaded ISO to a USB drive (8 GB or larger). Use one of these tools:

  • Ventoy — put multiple ISOs on one USB, great for trying multiple distros
  • Balena Etcher — simple cross-platform tool (Windows, macOS, Linux)
  • Fedora Media Writer — recommended for Fedora-based images

After flashing, verify the USB was written correctly before removing it.

3

Boot & Install

Plug in the USB and reboot. Enter your BIOS/UEFI boot menu (usually F12, F2, or Del) and select the USB drive.

  • Select Install KythOS from the boot menu
  • Follow the Anaconda installer — choose your disk, timezone, and language
  • Create your user account and set a password
  • Disk encryption is optional but recommended for laptops
  • Installation takes roughly 10–20 minutes depending on your hardware

When the installer completes, reboot and remove the USB drive.

4

First Boot Setup

KythOS will run a first-boot setup wizard (GNOME Initial Setup or KDE Welcome). Complete it, then:

  • Check for pending image updates: bootc upgrade
  • If an update downloads, reboot to apply it
  • Verify GPU drivers loaded correctly: glxinfo | grep renderer
  • Configure Flatpak remotes if any are missing
5

Set Up Gaming

Steam is pre-installed. Open it, sign in, and enable Steam Play:

  • Steam → Settings → Compatibility → Enable Steam Play for all titles
  • Install ProtonUp-Qt (via Flatpak) to add Proton-GE for extra game compatibility
  • Heroic Games Launcher is available for Epic Games and GOG libraries
  • Lutris covers Battle.net, Ubisoft Connect, and other launchers
  • MangoHud is pre-installed — add MANGOHUD=1 %command% to any Steam launch option
6

Check Compatibility & Play

Before diving in, look up your games on ProtonDB:

  • Visit ProtonDB.com and search for your game
  • Apply any recommended Steam launch options for your title
  • For anti-cheat games, check if EAC/BattlEye Linux is supported
  • If a game is broken on Proton stable, try Proton-GE (installed via ProtonUp-Qt)

The Ecosystem

Other Recommended Distros

These are community-recommended projects we think are excellent. If KythOS isn't right for you, one of these probably is.

Recommended

Bazzite

Immutable gaming-focused Fedora image

  1. Pick image: Download from bazzite.gg — choose Desktop, Handheld, or Nvidia variant.
  2. Create USB: Flash with Fedora Media Writer, Balena Etcher, or Ventoy.
  3. Install: Boot live media, run the Anaconda installer, set disk/timezone/user.
  4. First boot: Complete Yafti setup wizard, check GPU driver status.
  5. Gaming: Steam is pre-installed. Sign in, enable Steam Play, add Heroic/Lutris if needed.
  6. Validate: Check game compatibility at ProtonDB and apply any launch options.
Download Bazzite Bazzite Docs
Recommended

CachyOS

Performance-tuned Arch-based distro

  1. Download ISO: Get the latest from cachyos.org/download.
  2. Prepare USB: Flash and boot live environment with UEFI enabled.
  3. Calamares setup: Choose desktop, kernel (linux-cachyos recommended), and partitioning.
  4. Post-install sync: Run sudo pacman -Syu and refresh mirrors before installing games.
  5. Gaming stack: Install Steam from the repos, Proton-GE via ProtonUp-Qt, MangoHud, GameMode.
  6. Tune + test: Enable the BORE scheduler, validate FPS baseline, apply governor tweaks.
Download CachyOS CachyOS Wiki
Recommended

Aurora

Immutable workstation for devs who game

  1. Select image: Go to getaurora.dev — pick Aurora (gaming) or Aurora DX (dev tools included).
  2. Create installer: Fedora Media Writer is the recommended tool per project docs.
  3. Install system: Complete Anaconda guided install and reboot into your new immutable base.
  4. Initial setup: Run first updates, configure Flatpak sources and app permissions via Flatseal.
  5. Gaming tools: Install Steam Flatpak, enable Proton, sign into game launchers.
  6. Verify workflow: Test one game, check controller / audio / display, snapshot your settings.
Download Aurora Aurora Docs
Recommended

Nobara

Fedora-based distro tuned for gaming

  1. Download ISO: Get the latest from nobaraproject.org.
  2. Create USB: Flash with Ventoy, Balena Etcher, or Fedora Media Writer.
  3. Install: Boot the live environment, run the installer, complete user/timezone/storage setup.
  4. First update: Run sudo dnf upgrade --refresh and reboot once to get current kernel and drivers.
  5. Gaming setup: Install Steam, enable Steam Play for all titles, add ProtonUp-Qt for Proton-GE.
  6. Validate titles: Test a game and check fixes on ProtonDB if needed.
